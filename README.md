# IA aplicada a procesos empresariales

## Sobre este repositorio

Este repositorio reúne cinco ejercicios prácticos de Prompt Engineering realizados durante mi formación en Inteligencia Artificial en ITeducation.

Mi objetivo es aprender a utilizar herramientas de IA para identificar problemas, optimizar procesos y explorar oportunidades de automatización en pequeñas empresas y emprendimientos.

## Contenido

Los proyectos abordan:

1. Diagnóstico y organización empresarial.
2. Desarrollo de un prototipo de gestión de stock mediante Vibe Coding.
3. Comparación de herramientas de gestión de proyectos.
4. Identificación de tareas repetitivas con potencial de automatización.
5. Diseño de procesos de trabajo asistidos por IA.

## Metodología

Cada ejercicio incluirá el prompt utilizado, su objetivo, las herramientas empleadas, las pruebas realizadas y las conclusiones obtenidas.

## Estado

Proyecto académico en desarrollo. Los ejemplos simulados serán identificados como tales y las pruebas se documentarán a medida que se completen.
