# IA aplicada a procesos empresariales

## Estado

Proyecto integrador de Prompt Engineering finalizado en octubre de 2026, durante mi formación en Inteligencia Artificial en ITeducation.

El repositorio contiene cinco ejercicios prácticos con instrucciones, resultados y validaciones documentadas.

Los proyectos incluyen casos reales y escenarios simulados, identificados en cada archivo. Algunas propuestas de automatización fueron evaluadas conceptualmente y no representan implementaciones en producción.

Este repositorio constituye una primera etapa de aprendizaje y podrá ampliarse durante los siguientes módulos de formación.

## Contenido

Los proyectos abordan:

[1. Diagnóstico y organización empresarial.](https://github.com/kelemenagustin-png/IA-procesos-empresariales/blob/main/prompts/01-diagnostico-empresarial.md)
2. [Desarrollo de un prototipo de gestión de stock mediante Vibe Coding.](https://github.com/kelemenagustin-png/IA-procesos-empresariales/blob/main/prompts/02-app-stock-v0.md)
3. [Comparación de herramientas de gestión de proyectos.](https://github.com/kelemenagustin-png/IA-procesos-empresariales/blob/main/prompts/03-comparacion-herramientas.md)
4. [Identificación de tareas repetitivas con potencial de automatización.](https://github.com/kelemenagustin-png/IA-procesos-empresariales/blob/main/prompts/04-identificacion-de-oportunidades-de-automatizacion.md)
5. [Diseño de procesos de trabajo asistidos por IA.](https://github.com/kelemenagustin-png/IA-procesos-empresariales/blob/main/prompts/05-diseno-automatizacion.md)

## Metodología

Cada ejercicio incluirá el prompt utilizado, su objetivo, las herramientas empleadas, las pruebas realizadas y las conclusiones obtenidas.

## Estado

Proyecto académico en desarrollo. Los ejemplos simulados serán identificados como tales y las pruebas se documentarán a medida que se completen.
